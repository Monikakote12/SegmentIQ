SegmentIQ – Customer Segmentation Dashboard

SegmentIQ is a frontend web development mini project built using HTML, CSS, and JavaScript. It provides an interactive and user-friendly dashboard to explore customer segments, customer information, marketing campaigns, and business analytics.

The project focuses on creating a modern web interface that demonstrates how customer data and segmentation concepts can be presented visually.

✨ Features

Modern and responsive landing page.

User registration and login pages.

Interactive dashboard.

Customer analytics and KPI cards.

Six customer segments:

VIP Champions

High-Value Loyalists

New Prospects

At-Risk Churners

Occasional Buyers

Dormant Accounts

Customer directory with search and filtering.

Marketing campaign management interface.

Customer insights demonstration.

Revenue and customer analytics charts.

Reports interface.

Integrations showcase.

User profile and settings interface.

Sample customer data for dashboard demonstration.

🛠️ Technologies Used

HTML5 – Webpage structure.

CSS3 – Styling, layouts, and responsive design.

JavaScript – Interactive elements and dashboard functionality.

LocalStorage – Browser-based demo data and session handling.
